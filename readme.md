# 💌 Convite pra Tatiane

Um convite de jantar interativo, feito com muito carinho (e uma piada interna sobre a lua e as estrelas 🌙✨).

## 🔗 Ver o convite

👉 [Clique aqui pra abrir](https://kaia-boo.github.io/convite_restaurante/)

## ✨ Como funciona

- Um envelope selado aparece na tela — é só tocar nele pra abrir.
- O convite revela a data, o horário e uma mensagem especial.
- Tem um botão "Sim, aceito 💛" que confirma o convite.
- E um botão "não" que foge do mouse... porque não, né. 😏

## 🛠️ Feito com

- HTML, CSS e JavaScript puros — um único arquivo, sem dependências.
- Fontes: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) e [Quicksand](https://fonts.google.com/specimen/Quicksand), via Google Fonts.

## 📁 Sobre este repositório

Este repositório contém apenas o arquivo `index.html` com o convite, hospedado via [GitHub Pages](https://pages.github.com/).
